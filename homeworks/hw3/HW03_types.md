# HW3. Семантические проверки и типы

## Цели

- Добавить проверки имен и типов в AST.
- Проверять корректность типов (параметры/возвраты с явной аннотацией; локальные можно оставлять без аннотации, см. бонус).
- Подготовить аннотированный AST для оптимизаций и генерация кодаерации.

## Задание

1. Таблицы символов: области видимости, повторные объявления, использование до объявления.
2. Типизация: правила для выражений, операторов, вызовов функций; проверка сигнатур и числа аргументов.
3. Унификация для простых типов (int/bool/string/func) или выбранного подмножества.
4. Диагностика: сообщения об ошибках с позициями токенов/узлов.
5. Аннотированный AST: хранить тип каждого выражения для последующих этапов.

## Требования к реализации

- Использовать парсер/AST из HW2.
- Явно описать поддерживаемые конструкции и типы.
- При обнаружении нескольких ошибок - не останавливать после первой (по возможности).
- Бонус: вывод типов локальных переменных (аннотация опциональна, тип выводится из первого присваивания; см. критерии).

## Вход/выход

- Вход: текст программы.
- Выход: аннотированный AST (формат на выбор) + список ошибок (если есть).

## Тестирование

- Позитивные примеры: корректные типы, перегрузки/приведения (если поддерживаются).
- Негативные: неизвестные имена, повторные объявления, несовместимые типы, неверное число аргументов.
- Проверка, что ошибки содержат позицию и понятное описание.

## Формат сдачи

- Код + README (запуск, поддерживаемые конструкции).
- Набор тестов (положительных и отрицательных) с ожидаемыми ошибками.
- Краткий отчёт о типах и ограничениях.
- Формат аннотированного AST, пригодный для HW4/проекта.

## Критерии оценки (10 баллов + бонус)

- Таблицы символов и проверки имен - 2 балла
- Проверка типов (включая функции, параметры/возвраты, локальные с явным типом) - 4 балла
- Диагностика (позиции, ясность) - 2 балла
- Тесты и документация - 2 балла
- Бонус +2 б: вывод типов локальных переменных без аннотации (тип по первому корректному присваиванию;
  противоречия/невозможность вывода = ошибка).
